# Aturan Git & GitHub Auto Push

Ketika pengguna meminta "git ke github", "update github", "push github", atau instruksi serupa:
1. Langsung jalankan eksekusi git (`git add`, `git commit`, `git push`) tanpa harus membuat rencana (implementation plan) atau meminta konfirmasi terlebih dahulu.
2. Selalu pastikan file `tugas.txt` tidak ikut dimasukkan/di-commit ke GitHub.
